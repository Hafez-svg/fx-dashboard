# DRIFT — FX Trend Dashboard

یک داشبورد تحلیلی برای دنبال‌کردن روند دوازده جفت‌ارز اصلی با استفاده از استراتژی تقاطع میانگین‌های متحرک.

## ✨ ویژگی‌ها

### 📊 تحلیل هوشمند
- **استراتژی تقاطع میانگین متحرک**: تقاطع MA۵ و MA۲۰ برای شناسایی سیگنال‌های تجاری
- **بک‌تست واقعی**: محاسبه‌ی دقت بر اساس داده‌های گذشته (۱۲۰ روز)
- **محاسبه‌ی نوسان**: معیار دیگری برای ارزیابی ریسک

### 🎨 واسط کاربری
- **تم‌سوئیچ**: انتخاب بین تم تاریک و روشن
- **جستجو و مرتب‌سازی**: فیلتر کردن جفت‌ارز و مرتب‌سازی براساس دقت یا نوسان
- **چارت‌های تعاملی**: نمایش داده‌های بزرگ‌نمایی‌شده در مدال
- **انیمیشن‌های نرم**: تجربه‌ی کاربری بهتر

### 💾 صادرات داده
- **CSV Export**: خروجی داده‌ها به فرمت CSV
- **JSON Export**: خروجی تفصیلی به فرمت JSON
- **Local Storage**: ذخیره‌ی تنظیمات و تم

### 🔄 قابلیت‌های پیشرفته
- **تایم‌اوت API**: مدیریت درخواست‌های طولانی
- **تلاش مجدد خودکار**: سه بار تلاش مجدد در صورت شکست
- **Fallback URLs**: سه آدرس مختلف برای دریافت داده
- **Cache System**: ذخیره‌ی داده‌ها برای بهبود عملکرد

## 🔧 تنظیمات

تمام تنظیمات در `config.js` قابل تعدیل‌اند:

```javascript
CONFIG.ANALYSIS.SHORT_WINDOW = 5;    // دوره میانگین کوتاه
CONFIG.ANALYSIS.LONG_WINDOW = 20;    // دوره میانگین بلند
CONFIG.ANALYSIS.DAYS_BACK = 130;     // روز‌های عقب‌گرد برای داده
CONFIG.API.TIMEOUT = 8000;           // تایم‌اوت API (میلی‌ثانیه)
CONFIG.API.RETRY_ATTEMPTS = 3;       // تعداد تلاش‌های مجدد
```

## 📝 توضیحات فنی

### فرمول‌های استفاده‌شده

**Simple Moving Average (SMA):**
```
MA = (Sum of prices in period) / Period
```

**Volatility:**
```
Volatility = sqrt(Variance of prices)
```

**Accuracy:**
```
Accuracy = (Correct predictions) / (Total predictions)
```
